
# 📊 EDA on Netflix Dataset

## 📌 Project Description

This project performs **Exploratory Data Analysis (EDA)** on the Netflix dataset to uncover meaningful insights about movies and TV shows available on the platform. The goal is to analyze content trends, genres, ratings, and global distribution using data visualization techniques.

---

## 🎯 What This Project Does

* Cleans and preprocesses raw Netflix dataset
* Analyzes movies and TV shows data
* Identifies trends in content release over the years
* Explores popular genres, ratings, and countries
* Visualizes insights using graphs and charts

EDA helps in understanding patterns and making data-driven decisions. ([GitHub][1])

---

## ✨ Features

* 📂 Data Cleaning & Preprocessing
* 📊 Data Visualization using Matplotlib & Seaborn
* 🎬 Movie vs TV Show Analysis
* 🌍 Country-wise Content Distribution
* 📅 Year-wise Release Trends
* ⭐ Rating Analysis
* 🎭 Genre Insights

## 📊 Key Insights

* Movies are more in number compared to TV Shows
* Drama, Comedy, and International genres are most popular
* Most content is produced by a few top countries
* Recent years show growth in TV Shows
