
# 🎬 Netflix EDA 

## 📌 Project Description

This project demonstrates how blockchain can be used to store and access insights derived from Exploratory Data Analysis (EDA) on the Netflix dataset. Using Soroban smart contracts on the Stellar network, analyzed results such as top genres, ratings, and trends are stored in a decentralized and tamper-proof way.

---

## 🚀 What it does

- Stores analyzed Netflix dataset insights on-chain
- Allows retrieval of EDA results anytime
- Demonstrates integration of Data Science + Blockchain
- Ensures data integrity and transparency

---

## ✨ Features

- 📊 Store key insights (e.g., most popular genre, average rating)
- 🔍 Retrieve stored analytics anytime
- 🧾 Immutable data storage on blockchain
- ⚡ Fast and low-cost execution using Soroban
- 🔐 Tamper-proof and decentralized
